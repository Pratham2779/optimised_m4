M⁴ Meta-Memory: Cognitive Four-Layer Architecture

Based on: Bin Liang et al., IEEE Transactions on Audio, Speech, and Language Processing, Vol. 34, 2026.

L1 Category-Based Memory Learning

Analyzes incoming dialogue turns to extract discrete factual statements, personal preferences, and temporal markers. Dynamically assigns each clue to high-level semantic categories (e.g., Daily Life, Relations, Work, Hobbies).

L2 Chain-Based Memory Construction

Structures extracted clues into chronological memory chains stored in Neo4j. Encodes semantic representations using 384-dimensional embeddings (all-minilm) and connects nodes using chronological directed edges.

L3 Self-Monitoring-Based Memory Updating

Models memory retention via the mathematical Ebbinghaus Forgetting Curve ($R = e^{-t/S}$). Automatically performs "Calibrate" to resolve conflicting statements and "Compress" to synthesize dormant facts, keeping graph size compact.

L4 Self-Reflection-Based Memory Retrieval

Uses LLM self-reflection to locate category entry points, followed by Algorithm 1 bidirectional graph traversal. Evaluates retrieval confidence dynamically to extract only minimal, highly relevant subgraphs for final answer generation.
